# أوردرات المندوب

واجهة ويب عربية لمعالجة ومراجعة الطلبيات من ملفات PDF. تعمل بالكامل داخل المتصفح، ولا تحتاج إلى خادم أو خطوة بناء.

## تشغيل محلي

افتح `index.html` في متصفح حديث، أو استخدم خادم ملفات محليًا. يُفضّل استخدام رابط HTTPS لتوافق أفضل مع ميزات المتصفح.

## النشر على GitHub Pages

تم إعداد GitHub Actions للنشر تلقائيًا عند الدفع إلى الفرع `main`، ويمكن تشغيله يدويًا من تبويب **Actions** عبر سير العمل **Deploy to GitHub Pages**.

1. ادفع الملفات إلى مستودع GitHub على الفرع `main`.
2. في إعدادات المستودع، افتح **Pages** واجعل **Build and deployment** يستخدم **GitHub Actions** إذا لم يُفعّل تلقائيًا.
3. بعد نجاح سير العمل، افتح:

	https://abdelrahmanelshamyae-rgb.github.io/orders/

## الاستخدام على الأجهزة

الموقع متجاوب ويعمل عبر رابط Pages على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر باستخدام متصفح حديث واتصال بالإنترنت. تُحمّل مكتبات PDF والتنسيق والخطوط من CDN، لذا يلزم اتصال بالإنترنت.

تُعالج ملفات PDF المختارة داخل المتصفح ولا تُرفع إلى الموقع. يُحفظ المظهر والقوالب الاختيارية في التخزين المحلي للمتصفح، أما الطلبات وصور صفحات الملف فتبقى في جلسة الصفحة الحالية فقط لمنع استعادة بيانات أو صور قديمة.

تبدأ كل عملية رفع جلسة مستقلة، ولا تُستعاد الطلبات أو صور الصفحات من ملف سابق بعد تحديث الصفحة. تُحفظ قوالب تخطيط الأعمدة اختياريًا في المتصفح، ولا يُطبّق أي قالب تلقائيًا؛ يتطلب تطبيقه تطابق عناوين الحقول وأبعاد الصفحة ومواقع العناوين. جميع السجلات تحتاج مراجعة صورة صفها وتأكيدها يدويًا قبل تفعيل فتح واتساب.

إذا تعذر اكتشاف عناوين الأعمدة أو حدود الصفوف، افتح **ضبط أعمدة كشف PDF** لاختيار الحقول وتحريك حدود الأعمدة والصفوف يدويًا. تبقى رسائل واتساب مقفلة إلى أن يعتمد تخطيط كل صفحة وتؤكد بيانات كل طلبية.
